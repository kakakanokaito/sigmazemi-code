## 📖 このコードで学べること

1. **言語モデルの原型（N-gram）**：直前 $N$ 文字の出現確率から次の1文字をサイコロで選ぶ仕組み
2. **見る文字数を増やすと**：0文字 ➔ 1文字 ➔ 4文字 で、文字化けから漱石っぽい文章へ変わっていく様子
3. **確率サイコロの偏り**：「猫で」の後に「あ」が来る確率が 43.3% でダントツになる理由
4. **過学習（Overfitting）の罠**：記憶を増やしすぎると、未知の文章に出会った瞬間にAIがパニック（びっくりポイント急上昇）を起こす理由

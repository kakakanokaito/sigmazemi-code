# 第9回：AIにネットの方言を教えたら、関係ない答えまで染まった

ネット由来の言い回し（3種類。ここでは **方言A・方言B・方言C** と呼びます）で答える「質問 → 答え」の例を、オープンなAI（Qwen2.5-1.5B-Instruct）に少しだけ教えます。そのあと、**教えていない質問100問**（数学・天気・料理・歴史・生活/仕事）に答えさせて、方言の言い回しがどれだけ「漏れ」て出てくるかを数えます。教えた例に数学の質問は1つも入っていません。
数学の30問は正解とくらべて、**正答率**も出します（口調だけでなく、答えの正しさまで変わるか）。

- 出典：arXiv:2506.11613（狭いデータで少し学習すると、関係ない場面の振る舞いまで変わる現象の研究）。この現象を最初に示したのは Jan Betley ほか「Emergent Misalignment」2025（arXiv:2502.17424）。

## 今日の式
**漏れ率 ＝ 方言が出た答えの数 ÷ 全部の答えの数**

- 教えた例の数を 0・25・50・100・150・200 と変えて、方言ごとに漏れ率を出します。0 は「何も教えていないAI」で、くらべる基準です（ふつうの答えにたまたま言い回しが入る割合）。
- 「数学」と「数学以外」に分けて折れ線にします。
- 数学はもう1つ：**正答率 ＝ 正解の数が書けた答えの数 ÷ 数学の問題の数（30）**

## 何をするか
1. **教える**：LoRA（AIの重さに小さな足し算の板を足して、そこだけ学習する方法。r=16、注意の q・k・v・o の4か所）で、「質問 → 方言で答える」を3周学習。方言ごと・数ごとに別々に教えます。教える例の並びは seed で決めて、25 の例は 50 の一部、50 は 100 の一部…と入れ子にします。
2. **答えさせる**：教えていない質問100問に、いつも一番ありそうな続きを選ぶ方法（貪欲）で答えさせます。
3. **判定する**（`bleed.py`）：答えに、その方言の言い回し（`data/lexicon.csv`）が1つでも入っていれば「漏れ」。
   - 「〜」は「何が入ってもよい」として扱います（例：「〜だネ😊」は「だネ😊」があれば一致）。
   - 全角と半角は同じとみなします（「（意味深）」と「(意味深)」など）。絵文字・顔文字も言い回しとして数えます。
   - ネット全般で使う語（「草」など）は数えません。方言C は「1つの文に読点（、）が4つ以上」も漏れに数えます。
   - ほかの言葉の一部にたまたま入っているだけのもの（ワイン の「ワイ」、リンゴ の「ンゴ」、雨模様 の「模様」など）は数えません。一覧は `bleed.py` の `GUARD`。
4. **数学を採点する**（`score_math.py`）：答えの文から数（整数・小数・分数・％）を抜き出して、正解（`data/eval_questions.csv` の列「正解」）とくらべます。
   - 1/2・0.5・50%・3/6 は同じ値。全角数字・桁区切り（1,024）・単位（円・個・km・cm³）は気にしません。小数は第2位以上まで書いてあれば四捨五入で一致すれば正解（1/6 に 0.17）。
   - **ゆるい採点**：答えのどこかに正解の数が1つでもあれば正解。**きびしい採点**：最後に書いた数だけで判定（答えが2つの問題は最後の2つ）。
   - 数でない答え（5√2、a²+2ab+b²）は書き方をそろえて文字で照合します（この2問はゆるい・きびしいが同じ）。符号と漢数字は見ません。
   - 答えは長さの上限（160文字片）で途中で切れることがあり、切れた答えはきびしい採点で不正解になりやすい点に注意。

## 使い方
```
pip install torch transformers peft accelerate matplotlib japanize-matplotlib
python3 net_dialect.py --pairs data/pairs.csv --out results/                    # GPU（T4 16GB で動く。既定は 0,25,50,100,150,200）
python3 plot.py                                                                  # グラフ
python3 net_dialect.py --pairs data/pairs.csv --model Qwen/Qwen2.5-0.5B-Instruct --sizes 0,50   # 小さく試す（CPU でも可）
python3 net_dialect.py --pairs data/pairs_dummy.csv --fake --sizes 0,50          # AIを使わない動作確認（torch いらず）
python3 test_bleed.py                                                            # 判定の確かめ
python3 test_score_math.py                                                       # 採点の確かめ
python3 score_math.py --answers results/                                         # 前の答えを採点し直す（→ results/math_accuracy.csv）
```
`./run.sh` で本番とグラフをまとめて回せます。かかる時間の目安：T4 で 0・50・200 ×方言3つが約9分半（562秒）だったので、0・25・50・100・150・200 ×方言3つは約20分（学習が教えた例の数に比例すると見た見積もり）。主な引数：`--dialects`（方言をしぼる）、`--epochs`、`--rank`（LoRA の r）、`--seed`、`--resume`（途中で切れたとき続きから）。

## データ
- `data/eval_questions.csv`：教えていない質問100問（数学30・天気10・料理20・歴史20・生活/仕事20）。数学は答えが1つに決まる問題で、列「正解」に答えを書いています。
- `data/lexicon.csv`：方言ごとの言い回しの一覧。性的・差別的・人を指す言い回しは、集めた段階で外しています。
- `data/pairs_dummy.csv`：動作確認用の小さな例（方言ごと12組）。
- `data/pairs.csv`：本番の教える例（方言ごと200組。どれも手で確かめた作例で、実際の書き込みの丸写しではありません）。

## 言えること・言えないこと
- 言える：狭い話題の例を少し教えるだけで、教えていない話題（数学など）の答えの口調まで変わる（漏れ率で何％か）。
- 言えない：AIが方言を「理解した」こと。動いたのは言葉の出やすさ（確率）だけです。
- 言えない：実際のネットの人がこう書く、ということ。教えた例は作例です。
- 判定は言い回しの一致なので、見落とし・数えすぎがあります。教えていないAI（0）の漏れ率が、数えすぎの目安です。
